# Numerical Bisection Calculator

A web-based calculator for solving nonlinear equations using the Bisection Method.

## Features

* Enter a mathematical equation
* Set lower and upper bounds
* Set error tolerance
* Calculate the root using the Bisection Method
* Display iteration results

## Techstack

* Python
* Flask
* SymPy
* HTML
* CSS
* JavaScript

## How to Run

1. Clone the repository.
2. Install the dependencies:

```bash
pip install -r requirements.txt
```

3. Run the application:

```bash
python app.py
```

4. Open the local URL shown in the terminal.

## Project Purpose

Created as a learning project to implement numerical methods in a web application.
